# 🏟️ Cancha Ya - Sistema de Reservas

Plataforma integral para la gestión de canchas de Padel y Fútbol, diseñada para ofrecer una experiencia rápida al usuario y un control total al administrador.

## 🚀 Funcionalidades
* **App Clientes:** Selección de cancha, formulario de contacto e integración con Mercado Pago.
* **Panel Admin:** Visualización de reservas en tiempo real y gestión de turnos finalizados (botón Finalizar).
* **Base de Datos:** Sincronización instantánea con Firebase Firestore.

## 🛠️ Tecnologías
* **Frontend:** HTML5, CSS3 (Diseño responsivo y Modo Oscuro), JavaScript.
* **Backend:** Firebase (Hosting & Firestore).
* **Pagos:** Mercado Pago SDK.

## 📖 Instrucciones de Despliegue
1. Tener instalado `firebase-tools`.
2. Ejecutar `firebase deploy --only hosting`.
3. El panel de gestión se encuentra en `/admin.html`.
